- Build and test wheels with cibuildwheel in the new `wheels.yml` workflow. `release.yml` uses it for every tag, and pull requests that change the build run it. `scripts/test_wheel.py` checks that the compiled modules and commands come from the wheel, then runs the test suite from a copy outside the source tree. `setup.py` passes `-ffp-contract=off` only to compilers that understand it (not MSVC).
