# Water box: 2000 rigid TIP3P molecules

Start structure (`input.rst`, positions and velocities) and molecule descriptor
(`moldescriptor.dat`) of the `h2o_mm-mshake` example of
[PQ](https://github.com/MolarVerse/PQ/tree/dev/examples/h2o_mm-mshake), the
example used there for the O-O radial distribution function. The cubic box has
a length of 39.4491 A; 128 of the 2000 molecules are split by the periodic
boundary, which makes the file a good test of centers of mass.
